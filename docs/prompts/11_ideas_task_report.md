# 🌳 초록숲 재단 공익 캠페인 전략 기획안  
### _“작은 실천, 큰 변화 – 내 숨을 위한 한 평의 숲”_  
**작성자:** 유어미디어 고객관리팀 / 김민준 팀장  
**작성일:** 2025.10.28  

---

## Ⅰ. 고객 요구 분석 및 Pain Point 도출

| 구분 | 내용 |
|------|------|
| **핵심 목표** | ‘도시 숲 조성’의 필요성에 대한 국민 인식 개선 및 시민 참여 유도 |
| **핵심 메시지** | “작은 숨결이 모여 숲이 된다” — 연대감과 희망 중심의 스토리 |
| **Pain Point ①** | 한정된 예산(5천만 원) – TV, 라디오, 온라인 동시 집행 부담 |
| **Pain Point ②** | 공익광고 경험 부족 – 미디어 협상, 후원 유치 역량 한계 |
| **Pain Point ③** | 메시지 경쟁력 부족 – 상업광고 속에서 묻힐 우려, 감성 차별화 필요 |
| **Pain Point ④** | 세대 확장 한계 – SNS 위주 캠페인으로 중장년층 접근성 낮음 |

---

## Ⅱ. 전략 인사이트 (Strategic Insight)

1. **명분 기반 후원형 미디어 믹스 전략**  
   → 공익 메시지에 공감하는 방송사·브랜드의 후원 협찬 유도 (ESG 연계)  
2. **단일 핵심 콘텐츠 중심의 확장형 구조**  
   → 30초 메인 영상(TV+디지털 겸용)을 중심으로 라디오/온라인/SNS 버전 재가공  
3. **참여형 내러티브 전략**  
   → ‘내 숨 캠페인 챌린지’ 등 시민 참여형 확산 (비용 효율적 구조)  
4. **감성 스토리텔링 중심의 브랜디드 PSA**  
   → 다큐멘터리 감성 + 실제 시민 인터뷰로 신뢰도와 공감 동시 확보
