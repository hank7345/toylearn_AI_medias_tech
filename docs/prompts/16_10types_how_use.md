## I. Executive Summary (경영진 요약)

고객사의 유튜브 채널 **평균 시청 지속 시간(AVD)** 이 이전 분기 대비 **30% 급감**했습니다.
이는 단순한 성과 저하를 넘어 **유튜브 알고리즘 신뢰도 손상**을 의미합니다.

> 🎯 **핵심 진단 요약**
>
> 1. 숏폼 경쟁 환경 속에서 시청자 기대(Hook) 충족 실패
> 2. 메타데이터(썸네일/제목)와 콘텐츠 내용 불일치로 인한 ‘Poor Quality Clicks’ 유입

이에 따라,

* **단기적으로는 도입부 최적화 및 A/B 테스트 기반 복원 전략**
* **중장기적으로는 Live Commerce 및 LTV 기반 통합 리텐션 전략**
  을 제안합니다.

📈 **목표:**

* 90일 내 AVD **+15% 회복**
* 고가치 시청자 세그먼트의 **이커머스 전환율 +20%**

## II. Situation Analysis: Performance Gap 진단 및 비즈니스 영향

### 🔹 A. 문제 정의: AVD 30% 급감의 비즈니스 심각성

AVD 하락은 유튜브 알고리즘이 콘텐츠를 “비추천 대상”으로 분류하게 만드는 주요 원인입니다.

| 비즈니스 영향    | 내용                      |
| ---------- | ----------------------- |
| **노출 감소**  | 추천 시스템에서 제외되어 유기적 성장 둔화 |
| **ROI 하락** | 콘텐츠 투자 대비 시청 효율 저하      |
| **전환 저하**  | 제품 가치 전달 실패 → 구매 전환률 감소 |

---

### 🔹 B. 외부 환경 분석: 시청자 행태의 구조적 변화

* **숏폼 콘텐츠 지배력 확대:** 롱폼 대비 2.5배 높은 참여율
* **시청자 기대치 상승:** “첫 5초 가치 제안” 실패 시 즉시 이탈
* **UGC 중심 소비:** 진정성과 공감 중심의 콘텐츠 선호

> 현재 AVD 급감은 시청자 “시간 경쟁”에서의 패배를 의미합니다.

## III. Root Cause Analysis (RCA): MECE 로직 트리 기반 원인 점검

### 📘 MECE 기반 진단 구조

| 대분류                | 중분류                      | 핵심 가설              | 진단 근거 및 시사점          |
| ------------------ | ------------------------ | ------------------ | -------------------- |
| **I. 유입 효율성 문제**   | 1. 메타데이터 불일치             | 썸네일/제목 과장 → 불일치 유입 | CTR 높고 AVD 낮은 패턴 발생  |
|                    | 2. 아웃라이어 효과              | 비구독자 확산 → 낮은 만족도   | 조회수↑, AVD↓ = 알고리즘 불신 |
| **II. 콘텐츠 관여도 문제** | 3. 도입부 실패 (Hook Failure) | 첫 5~30초 집중력 부족     | AVD 급락의 주 원인         |
|                    | 4. 포맷 전략 오류              | 포맷 변화로 기존 팬 이탈     | 채널 일관성 붕괴            |
|                    | 5. 제작 품질 저하              | 속도, 가치, 편집 약화      | 콘텐츠 기본 경쟁력 약화        |

---

### 💬 주요 인사이트

* **썸네일/제목 불일치 → 잘못된 유입**
* **초반 Hook 실패 → AVD 급락**
* 두 요인이 결합되어 “CTR↑ / AVD↓”의 악순환 발생
